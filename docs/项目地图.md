## 1. 项目定位

**Forza Fat Fish HUD**（仓库与程序集名仍为 `ForzaOverlay` / `ForzaFatFishHUD.exe`）是面向《极限竞速：地平线 4/5/6》的 Windows 遥测 HUD 悬浮层：接收游戏“数据输出”的 UDP 包，在游戏画面上叠加透明、点击穿透的实时仪表，并提供一套桌面设置中心。

核心特征：

- **HUD 走 GPU**：Direct3D 11 + Direct2D + DirectComposition 自绘覆盖层（`Rendering/`），WPF 只负责设置窗口与布局编辑器。
- **设置窗口即主界面**：1160×900 固定窗口，启动即显示；关闭 = 退出程序，最小化只最小化。
- **无托盘**：程序只有设置窗口与 HUD 两层界面，托盘图标已移除。
- **统一遥测端点**：一份 IP + 端口配置，监听指定地址；默认 `127.0.0.1:23333`。
- **三种仪表样式**：`经典` / `GHOST LADDER` / `SHIFT TREE`，三选一，各自保存独立布局。
- **HUD 面板**：行驶仪表（经典 / GHOST LADDER / SHIFT TREE 三选一）、轮胎与悬挂、HUD 资源占用、换挡提示（选配）；转向仪表已停用（代码保留）。
- **红区校正**：从遥测学习断油转速，按“车辆 + 最大转速 + PI”分档校正三块仪表的红区。
- **换挡提示**：4 灯提示（绿 / 黄 / 红 / 换挡点），手动挡专用，依赖红区校正。
- **超速提示音**：超过设定时速播放 MP3，次数（3 / 5 / 10 / 一直响）、间隔、音量与文件均可配置。
- **按画面比例分档布局**：16:9、16:10、21:9、32:9、48:9、自定义，六套布局互不覆盖。
- **可视化布局编辑器**：全屏拖拽、拖角缩放，Enter 保存、Esc 取消；模块清单由 `HudModuleCatalog` 驱动。
- **即时设置**：没有全局保存按钮，改动即写盘并立即生效；文本类字段失焦校验，行内提示成功/失败。
- **刷新率可选**：60 FPS / 30 FPS / 以游戏发包为准。
- **智能显隐**：默认开启「始终显示」，游戏在前台即显示；关掉后为智能显隐（驾驶中 + 游戏前台 + 时速高于 4 km/h，2 km/h 滞回关闭）。
- **自身开销可观测**：HUD 面板与设置页显示帧率 / CPU / 内存 / GPU / 显存。
- **权限自检**：本程序权限低于游戏时，「遥测选项」页顶部提示并可“以管理员身份重启”。
- **检查更新**：「关于」页请求 GitHub Releases，下载 zip 后由 PowerShell 脚本替换并重启。
- **内置字体与素材**：`Assets/Fonts/D-DIN-Bold.ttf`（OFL 1.1）、`Assets/Images/`（应用图标与角色形象）。
- **诊断日志**：每次运行一个日志文件，保留 7 天；记录未处理异常。

规范文档（与代码同级维护）：

- `docs/UI统一标准.md`：设置窗口的尺寸、颜色、字号、行版式、控件与交互规则。
- `docs/HUD模块开发说明.md`：HUD 渲染模型、视觉规范、布局模型、模块接入与性能预算。

## 4. 运行时全景

### 4.1 进程与线程

| 执行体 | 归属 | 说明 |
| --- | --- | --- |
| WPF UI 线程 | `App` / `SettingsWindow` / 超速音定时器 | 设置窗口、布局编辑器、更新窗口；500ms 显隐定时器、1s 性能读数、1.5s 日志刷新、120ms 超速提示音检测 |
| GPU 消息线程 | `GpuOverlayWindow`，线程名 `ForzaOverlay.GpuMessage` | 自建窗口类的 `GetMessage` 消息循环 |
| GPU 渲染线程 | `GpuOverlayWindow`，线程名 `ForzaOverlay.GpuRender` | 取包 → D2D 绘制 → `Present`；每帧结算 `PerformanceMonitor.Tick()` |
| UDP 接收循环 | `UdpTelemetryListener` 的 `Task.Run` | 单监听器；解析失败丢弃；异常后退避 100ms |
| 进程轮询线程 | `GameProcessMonitor` 的 `System.Threading.Timer` | 每 10s 扫描；`Interlocked` 防重入 |
| 热键回调 | NHotkey 消息循环线程（通常 UI 线程） | 切到 `TelemetryStateManager.Toggle()` |

### 4.2 数据流

```
《Forza Horizon 4/5/6》Data Out
        │  UDP / 324 bytes / 配置的 IP:端口（默认 127.0.0.1:23333）
        ▼
UdpTelemetryListener                            （后台线程）
        │  TelemetryPacketParser.TryParse
        ▼
Channel<TelemetryFrame>(capacity=1, DropOldest)   ← 只保留最新帧
        │
        ├─ AppServices.TryReadLatest → App.UpdateGpuVisibility（UI 线程，显隐判定）
        ├─ ShiftTreeScene.PumpPacket（渲染线程，绘制取数）
        │     └─ ShiftPointLearner.Update（红区校正开启时取样：断油点 / 升挡点）
        └─ OverspeedSoundPlayer（UI 定时器，超速判定与播放）
        ▼
ShiftTreeScene.Render                           （渲染线程，由 GpuOverlayWindow.Render 触发）
        ├─ 行驶仪表：经典 / GHOST LADDER / SHIFT TREE 三选一
        ├─ 轮胎与悬挂
        ├─ HUD 资源占用
        └─ 换挡提示（4 灯，红区校正 + 换挡提示开启时）
        ▼
ID2D1RenderTarget → swap chain → DirectComposition → 透明置顶窗口
```

### 4.3 启动时序（`App.OnStartup`）

1. 获取单实例互斥量 `Local\ForzaFatFishHUD.SingleInstance`；已存在则激活另一个实例的主窗口并退出。
2. `Diagnostics.BeginRun()` 创建本次日志。
3. 注册崩溃处理：UI 线程、后台线程、未观察任务异常。
4. `SettingsStore.Load()`；写启动配置日志。
5. `AppStartupValidator.IsValid()`：合法则 `AppServices.ApplySettings()`（注册热键 + 启动监听器）；非法只记日志。
6. 订阅 `GlobalHotkeyService.ToggleHudRequested`。
7. 创建 `GpuOverlayWindow` 与 `ShiftTreeScene`（场景内自建 `ShiftPointLearner`，存档目录 `<exe>/data`），挂接 `Render` 事件，`Start()` 建窗口与 D3D；成功则启动 500ms 显隐定时器，挂接 `IdleTick` / `HasNewPacket`，`ApplyGpuRefreshMode` 后立刻算一次显隐。
8. 创建并启动 `GameProcessMonitor`（立即首轮扫描），句柄变化时更新 `AppServices` 并做权限自检。
9. 创建并 `Show()` `SettingsWindow`（主界面）；创建 `OverspeedSoundPlayer` 并赋给 `OverspeedSoundPlayer.Shared`；随后注册全局热键。

### 4.4 退出时序（`App.OnExit`）

写退出日志 → 退订渲染事件 → 退订遥测开关事件 → 停显隐定时器 → 释放 `ShiftTreeScene` 与 `GpuOverlayWindow`（停线程、释放 D3D、销毁窗口）→ 退订并 `Dispose` 监控 → 退订热键并 `Clear()` → 关闭 UDP 监听器 → 释放 `OverspeedSoundPlayer` → `Dispose` 互斥量。

退出入口：设置窗口 ✕ / Alt+F4 / UI 线程未处理异常（提示后退出）。最小化只是 `WindowState.Minimized`。

### 5.1 `GpuOverlayWindow`（HUD）

**文件**：`src/ForzaOverlay.App/Rendering/GpuOverlayWindow.cs`

**窗口与设备**

- 自建窗口类 `ForzaOverlayGpuWindow`，样式 `WS_POPUP`；扩展样式 `WS_EX_NOREDIRECTIONBITMAP | WS_EX_LAYERED | WS_EX_TOPMOST | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`。
- `WM_NCHITTEST` 直接返回 `-1`，保证鼠标点击穿透到游戏。
- 设备链：D3D11 硬件适配器（`EnumAdapterByGpuPreference(HighPerformance)` 优先、跳过软件适配器）→ BGRA 支持的设备 → `CreateSwapChainForComposition`（`FlipSequential`、预乘 alpha、双缓冲）→ `DCompositionCreateDevice` + 视觉树挂 swap chain → 基于 `IDXGISurface` 的 `ID2D1RenderTarget`，`TextAntialiasMode = Grayscale`。
- 帧节奏：`RenderFrame` 内 `BeginDraw` → `Clear` 透明 → 触发 `Render` 事件 → `EndDraw` → `Present(0, None)` → `DComp.Commit()`。
- 节流：`SetRefreshMode(intervalMs, followPacketRate)`；隐藏时只触发 `IdleTick` 并 `Sleep(10ms)`，继续取包但不绘制。
- 生命周期：`Start()` 建窗口并起两条线程；`Dispose()` 停线程、释放 D3D、销毁窗口。

**面板与默认布局**

| 面板 | 基准尺寸 | 默认位置（X/Y/WidthRatio） | 显示条件 |
| --- | --- | --- | --- |
| 行驶仪表 · 经典 | 820 × 150 | .2700 / .7900 / .4600 | 行驶仪表开 + 样式 = 经典 |
| 行驶仪表 · GHOST LADDER | 420 × 238 | .4824 / .6738 / .2888 | 行驶仪表开 + 样式 = GHOST LADDER |
| 行驶仪表 · SHIFT TREE | 820 × 320 | .2628 / .6356 / .4809 | 行驶仪表开 + 样式 = SHIFT TREE |
| 轮胎与悬挂 | 220 × 212 | .0095 / .2680 / .1831 | 轮胎开关 |
| HUD 资源占用 | 200 × 140 | .8564 / .3932 / .1383 | 资源开关 |
| 换挡提示 · 4 灯 | 120 × 40 | .4242 / .1821 / .1524 | 红区校正开 + 换挡提示 = 4灯提示 |
| ~~转向仪表~~ | ~~220 × 118~~ | .4427 / .0167 / .1146 | 已停用（目录条目注释、布局字段保留） |

**缩放与定位**

- 每个面板统一：`scale = clamp(WidthRatio × 视口宽 / 基准宽, 0.05, 20)`，`left = 视口X + X × 视口宽`，`top = 视口Y + Y × 视口高`。
- 视口来自游戏客户区：`App.TryUpdateGpuViewport` 用 `GetClientRect` + `ClientToScreen` 取值，`ShiftTreeScene.SetViewport` 加锁写入；每次显隐刷新都会重新同步，尺寸变化时写一条“GPU 视口”日志，识别到游戏句柄时也立即同步一次。
- 位置与大小按归一化坐标还原，画面内不额外夹取；缩放必须用基准常量，禁用运行时 `ActualWidth`。

**三种仪表样式**

- `AppSettings.InstrumentStyle`：`Classic=0`、`Festival=1`、`ShiftTree=2`。
- 三者共用“行驶仪表”总开关 `ShowPerformancePanel`；样式决定绘制哪一个。
- 各自保存独立布局：`PerformanceLayout` / `FestivalLayout` / `ShiftTreeLayout`。

**经典仪表绘制**

- 820×150 圆角背景（透明度取 `BasicPanelBackgroundOpacity`），顶部 10px 转速条按转速比填充，颜色走 `RpmColorScale.At(ratio, #00C8E0, AmberColor, 红区比例)`：开启红区校正时红区取学习值，否则固定 0.90；红区前 10% 转黄、进入红区转红，均无渐变。
- 左侧三行“马力 / 扭矩 / 增压”（单位 千瓦 / 牛米 / bar），数值截断格式化；中间 90×100 档位框（58pt 档位 + “档位”）、34pt 转速、86pt 时速 + “km/h”。
- 右侧四根 18×77 踏板条（离/油/刹/手刹），高度上限 77；四色：离合 `#B388FF`（0.75 透明）/ 油门 `#4FC3F7` / 刹车 `#F44336` / 手刹 `#FFEB3B`。

**GHOST LADDER 绘制**

## 7. 关键机制

### 7.1 端点与监听器（`AppServices`）

- 只有一套端点：`TelemetryIp` + `TelemetryPort`。
- `ApplyActiveEndpoint` 解析 IP（非法回退 `127.0.0.1`），再交给 `RestartTelemetryListener(port, address)`。
- 若现有监听器的端口与地址都一致则复用；否则销毁重建。
- 端口非法（不在 1–65535）不监听并记日志。
- 监听器绑定 `IPEndPoint(bindAddress, port)`，开启 `ReuseAddress`。
- `TryReadLatest` 遍历监听器取帧；`TotalReceived` / `TotalDropped` 汇总计数。

### 7.2 324 字节包布局（Forza “sled” 格式）

`[StructLayout(LayoutKind.Explicit, Size=324)]`：

| 偏移 | 内容 |
| --- | --- |
| 0 / 4 | `IsRaceOn` (int)、`TimestampMs` (uint) |
| 8–19 | 引擎：最大 / 怠速 / 当前转速 |
| 20–67 | 加速度 XYZ、速度 XYZ、角速度 XYZ、Yaw/Pitch/Roll |
| 68–83 | 归一化悬挂行程 FL/FR/RL/RR |
| 84–99 | 轮胎滑移比 |
| 100–115 | 车轮转速 |
| 116–147 | 是否在减速带 / 是否在水坑 |
| 148–195 | 路面震动、滑移角、综合滑移 |
| 196–211 | 悬挂行程（米） |
| 212–231 | 车辆序号、级别、性能分、驱动形式、气缸数 |
| 232–243 | 车组、可破坏物速度差/质量 |
| 244–255 | 世界坐标 XYZ |
| 256–267 | 速度 (m/s)、功率 (W)、扭矩 (N·m) |
| 268–283 | 四轮胎温（华氏度） |
| 284–295 | 增压 (psi)、燃油比例、行驶距离 |
| 296–311 | 最佳/上一圈/当前圈/总时间 |
| 312–314 | 圈数 (ushort)、名次 (byte) |
| 315–322 | 油门/刹车/离合/手刹 (byte)、档位 (byte)、转向 (sbyte)、辅助线、AI 刹车差 |
| 323 | 尾部填充 |

换算：`3.6`（m/s→km/h）、`0.0689476`（psi→bar）、`0.001`（W→kW）、`0.001341022`（W→hp）。
`Gear=0` → `-1` → `R`；展示侧过滤 -1..10 之外的异常档位。只接受 324 字节。

### 7.3 显隐状态机

`TelemetryStateManager.IsTelemetryEnabled` 混合“用户开关”和“游戏运行”：

| 事件 | 结果 |
| --- | --- |
| 游戏启动（上升沿） | `true` |
| 游戏退出（下降沿） | `false` |
| 热键 | `Toggle()` |

HUD 真正显示还需 §5.1 的句柄/最小化/前台/驾驶/速度条件。`AlwaysShowHud` 跳过驾驶与速度门槛，但仍要求前台。

### 7.4 游戏识别（`GameProcessMonitor`）

按顺序尝试，拿到第一个有效句柄即返回：

1. **窗口枚举**：`EnumWindows` → 可见窗口 → 标题去空格后匹配 `ForzaHorizon4/5/6`。
2. **进程名**：`GetProcessesByName` → `MainWindowHandle`（最多 2 次，间隔 200ms）。
3. **全进程标题**：进程名 + 主窗口标题匹配。

轮询 10s；`Interlocked` 防重入；句柄或类型变化才触发事件；`CheckGameRunning` 也会做一次窗口枚举。

### 7.5 全局热键

- 设置界面提供 F1–F12 下拉；`HotkeyGesture` 仍支持 `Ctrl+Shift+Alt+Win+<Key>` 文本格式（供手工配置）。
- 选择后立即 `GlobalHotkeyService.TryApply`；失败回退旧值并提示“✕ 已被占用”。
- `AppServices.SuspendHotkey` / `ResumeHotkey` 保留（暂停/恢复当前热键）。
- 同一热键名 `ForzaOverlay.ToggleHud`，`AddOrReplace`。

### 7.6 轮胎视觉算法（`TireVisualEvaluator`）

| 阈值 | 值 | 颜色 |
| --- | --- | --- |
| 冷胎上限 | 52 ℃（±3） | `#4FC3F7` → 透明 |
| 最佳区间 | 55–82 ℃ | 透明 |
| 偏热上限 | 85 ℃（±3） | 透明 → `#FFEB3B` |
| 过热上限 | 113 ℃（±3） | 黄 → `#F44336` |

| 滑移绝对值 | 边框/特效 |
| --- | --- |
| ≤ 0.70 | 白，无 |
| 0.70–0.80 | 白→黄，`Warning` |
| 0.80–0.95 | 黄框，`Warning` |
| 0.95–1.05 | 黄→红 |
| ≥ 1.0 | `Critical`，红框 + 5Hz 闪烁（最低 30%） |

### 7.7 HUD 模块、三种仪表与布局

- `HudModuleCatalog.Modules` 是模块清单：经典仪表、GHOST LADDER、SHIFT TREE、轮胎与悬挂、HUD 资源占用、换挡提示 · 4 灯；转向条目已注释。
- 每项包含：名称、基准宽高、强调/填充色、`IsVisible(settings)`、`Read(profile)`、`Write(profile, layout)`。
- 三种仪表共用 `ShowPerformancePanel`；`IsVisible` 额外要求 `InstrumentStyle` 匹配。
- 布局为归一化 `X / Y / WidthRatio`，高度按基准宽高比推导；六套 Profile 对应六种比例。
- 渲染侧：`ShiftTreeScene.Render` 按样式分发到对应 `Draw*` 方法，矩阵变换还原位置与缩放。
- 编辑器侧：目录条目自动生成拖拽框；保存写回对应 Profile。
- 新增带动画/辉光的面板时，缓存几何与文本布局（`_brushCache` / `_arcCache` / `_textLayoutCache`）以免每次重建。

### 7.8 刷新率与渲染节流

| 设置值 | 含义 | 实现 |
| --- | --- | --- |
| `0` | 30 FPS | `SetRefreshMode(33, false)`，渲染线程按 33ms 目标间隔等待 |
| `1`（默认） | 60 FPS | `SetRefreshMode(16, false)`，目标间隔 16.5ms |
| `2` | 以游戏发包为准 | `SetRefreshMode(0, true)`，每帧查询 `HasNewPacket`，无新包则 2ms 后再试 |

- 目标间隔用 `SetWaitableTimerEx` 高精度等待，不可用时退化为 `Thread.Sleep`。
- 实际刷新率上限还受游戏发包频率与显示刷新率约束。
- 显隐定时器每次触发都会重新应用刷新率设置，因此改设置无需重启。

### 7.9 配置与即时提交

- 路径 `<exe>/config/config.json`；UTF-8、缩进 JSON；`ActiveLayout` 不序列化。
- 字段：`TelemetryIp`、`TelemetryPort`、`HotkeyText`、`ShowPerformancePanel`、`InstrumentStyle`、`EnableRedlineCalibration`、`ShiftHintStyle`、`ShowSteeringGauge`、`ShowTirePanel`、`ShowPerfPanel`、`BasicPanelBackgroundOpacity`、`HudRefreshRate`、`AlwaysShowHud`、超速音六项（`EnableOverspeedSound`、`OverspeedSpeedKmh`、`OverspeedSoundCount`、`OverspeedSoundDelayMs`、`OverspeedSoundVolume`、`OverspeedSoundPath`）、`HudAspectRatio`、`CustomAspectWidth/Height`、6 套 `HudLayoutProfile`。
- `HudLayoutProfile` 字段：`PerformanceLayout`、`FestivalLayout`、`ShiftTreeLayout`、`SteeringLayout`、`TireLayout`、`PerfLayout`、`ShiftHintRgb3Layout`。
- 默认：`127.0.0.1`、`23333`、`F3`、仪表经典、仪表/轮胎开、资源关、背景透明度 70、刷新率 60 FPS、**始终显示开**、**红区校正开**、**换挡提示关**、**超速音关**（200 km/h、5 声、200ms、音量 50、`Assets\Sounds\AE86windchime.mp3`）、比例 16:9、自定义 3440×1440。

### 7.10 诊断与崩溃

- `<exe>/logs/run-yyyyMMdd-HHmmss.log`，保留 7 天；单锁；写失败静默。
- 记录：启动配置、GPU 覆盖层与 D3D 初始化结果、首帧样式、游戏识别、显隐原因与切换、游戏窗口全屏/窗口化、UDP 监听成败、字体加载结果、权限判定、红区学习（确认/重学）、超速音（开始/就绪/播放/重置）、更新失败、异常。
- `WriteException` 输出类型、消息、堆栈与内部异常链。
- 崩溃处理：UI 线程异常记录并弹窗后退出；后台线程与未观察任务异常只记录。

### 7.11 单实例与权限

- `Mutex(true, @"Local\ForzaFatFishHUD.SingleInstance", out createdNew)`。
- 非首个实例会枚举同名进程，`ShowWindow(SW_RESTORE)` + `SetForegroundWindow` 激活已有窗口，然后自身退出。
- 权限自检：`ProcessPrivilege` 用 `TokenIntegrityLevel` 比较本程序与游戏进程；低一档时置 `AppServices.IsPrivilegeSufficient=false` 并触发 `PrivilegeStateChanged`，设置页显示“快捷键可能失效”横幅。
- “以管理员身份重启”先释放单实例互斥量，再以 `Verb=runas` 启动自身并 `Shutdown()`。

### 7.12 自身性能指标（`PerformanceMonitor`）

- `Tick()` 每帧调用，每 ≥1s 结算一次。
- `Fps`：渲染线程实际帧数 / 墙钟；`CpuPercent`：进程 CPU / 墙钟 / 逻辑核数 × 100；`MemoryMb`：工作集。
- `GpuPercent` 与 `VramMb` 读 Windows 性能计数器：类别 `GPU Engine`（`Utilization Percentage`）与 `GPU Process Memory`（`Local Usage`），按含 `pid_<当前进程>_` 的实例求和；类别缺失时静默为 0。
- 读取方：HUD 资源面板（每帧）与设置页读数条（1s）。

### 7.13 字体与数字定槽

- `Assets/Fonts/D-DIN-Bold.ttf`，SIL OFL 1.1，来源与授权见 `LICENSE.txt`；`csproj` 以 `CopyToOutputDirectory=PreserveNewest` 随输出复制。
- 加载方式：`IDWriteFactory5` 字体集装入该文件，`FindFamilyName` 依次尝试 `D-DIN` / `D-DIN Bold` / `D-DIN-Bold` / `D-DIN Condensed`；失败回退 `Bahnschrift`，并写一条日志。
- GHOST LADDER 时速：字形轮廓按 63 槽位排布 + 2px 描边；SHIFT TREE 转速/速度定槽 33 / 36。
- 其余 HUD 文本使用 Bahnschrift / Consolas / Microsoft YaHei UI 等系统字体。

### 7.14 检查更新与应用更新

- `UpdateService.CheckAsync` 请求 `api.github.com/repos/FatFishNet/forza-fatfish-hud/releases/latest`，取 `tag_name`、`body` 与第一个 `.zip` 资产。
- `IsNewer` 用 `Version` 比较；启动后 1.5s 静默检查一次，结果缓存在窗口内（一次运行只请求一次网络）；命中则显示“有可用更新”徽标，「关于」页手动检查复用该结果——无更新提示“已是最新版本”，有更新则打开 `UpdateWindow`。
- 下载到 `%TEMP%\ForzaFatFishHUD\`，全程 `IProgress<double>` 回报进度。
- `UpdateApplier` 生成 `apply-update.ps1`：等待 2s → 解压 → 复制到程序目录 → 重启 exe → 清理临时文件。
- 程序目录不可写（如 Program Files）时拒绝自动更新，提示手动到 GitHub Releases 下载。

### 7.15 红区校正与换挡提示（`ShiftPointLearner`）

- 存档：`<exe>/data/shift-learning.json`，键为 `CarOrdinal | CarClass | PI | 最大转速 | 怠速 | 驱动形式 | 气缸数`，换车/换调校自动分档；每 5s 落盘一次。
- 断油点识别：WOT（油门 ≥ 0.90、刹车 ≤ 0.05）+ 非 1 档打滑 + 持续转向 ≤ 0.5s + 转速 ≥ 最大转速 × 0.75，1.5s 窗口内需出现锯齿（≥ 2 次上升、≥ 3 次回落、振幅 ≥ 100 RPM 或低转机 ≥ 60）且速度不再上升；首次为候选值，二次在 ±2% 内才确认，中位数保存（最多 10 个样本，超 ±2% 连续 5 次则重学）。
- 红区换算：`红区 = 最大转速 − (最大转速 − 断油点) × 1.7`（断油比例 < 0.88 的老爷车用 1.9），夹在 0.50–0.98；未学到时回退 0.80。
- 换挡点：预警 = 断油点 × 0.93、最佳 = 断油点 × 0.98（夹在 0.30–1.0）；4 灯提示的换挡点按 `断油点 − (最大转速 − 断油点) × 0.32` 计算。
- 最高档：`Update` 每帧记录 `MaxGearSeen`（不受 WOT / 断油采样条件限制），`GetMaxGearSeen` 供查询；绘制侧已不据此跳过提示。
- 升挡采样：档位 +1 的瞬间，若上一帧油门 ≥ 0.80、转向 ≤ 0.20、平均滑移 ≤ 0.6，按档位记录（每档最多 5 条、总计 60 条，1 档不记）。
- 关闭红区校正时不采集样本（`PumpPacket` 里判断），避免产生用户未要求的数据。

### 7.16 超速提示音（`OverspeedSoundPlayer`）

- 触发：`EnableOverspeedSound` 开且 `IsRaceOn`，时速 ≥ `OverspeedSpeedKmh`；回差 3 km/h（降到阈值 −3 才重置），正在播放时不掐断，等这一遍播完再停。
- 次数：3 / 5 / 10 声或“一直响”（配置值 0）；每遍间隔 `OverspeedSoundDelayMs`（100–500ms），音量 `OverspeedSoundVolume`（0–100）。
- 播放：WPF `MediaPlayer` 播 MP3，`MediaOpened` 拿到真实时长后再排下一遍（120ms 定时器轮询，等媒体打开最多 1.5s）；文件缺失只记一条日志。
- 预览：设置页「播放」按当前设置试听、「停止播放」立即停；`Shared` 静态属性供设置窗口取用。

## 12. 更新协议（给未来的架构师）

### 第 1 步：检测变动

在仓库根目录运行（对比基线，输出 `ADDED / CHANGED / REMOVED`）：

```powershell
$base = (Get-Content 'docs\project-map.baseline.json' -Raw -Encoding UTF8 | ConvertFrom-Json).files
$current = @{}
Get-ChildItem -Path src,app-dist-template -Recurse -File -ErrorAction SilentlyContinue |
  Where-Object { $_.FullName -notmatch '\\(bin|obj|\.vs)\\' } |
  ForEach-Object {
    $rel = $_.FullName.Substring($PWD.Path.Length+1).Replace('\','/')
    $current[$rel] = (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash.ToLowerInvariant()
  }
Get-ChildItem -File -Path . |
  Where-Object { $_.Extension -ne '.log' -and $_.Name -ne 'Thumbs.db' } |
  ForEach-Object {
    $rel = $_.FullName.Substring($PWD.Path.Length+1).Replace('\','/')
    $current[$rel] = (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash.ToLowerInvariant()
  }
$base | ForEach-Object {
  if (-not $current.ContainsKey($_.path)) { "REMOVED $($_.path)" }
  elseif ($current[$_.path] -ne $_.sha256) { "CHANGED $($_.path)" }
}
$current.Keys | Where-Object { $_ -notin $base.path } | ForEach-Object { "ADDED $_" }
```

（无输出 = 无变动。）

### 附：重新生成基线

> 默认 shell 的 `Get-Content` 在 PowerShell 5.1 下按 ANSI（GBK）解码，`Publish.bat`、`Start.bat` 与 `app-dist-template` 下的 `.txt` 都是 GBK 编码；行数统计与编码无关，哈希始终按字节计算。
> 基线写成纯 ASCII：非 ASCII 字符转义为 `\uXXXX`。
> 二进制文件（字体、图标、图片）只记哈希与大小，行数记 0。

```powershell
$files = @(Get-ChildItem -Path src,app-dist-template -Recurse -File |
    Where-Object { $_.FullName -notmatch '\\(bin|obj|\.vs)\\' }) +
  @(Get-ChildItem -File -Path . |
    Where-Object { $_.Extension -ne '.log' -and $_.Name -ne 'Thumbs.db' })

$textExt = @('.cs','.xaml','.csproj','.props','.json','.ps1','.bat','.txt','.md','.sln','.manifest','.gitattributes')

$rows = foreach ($f in ($files | Sort-Object FullName -Unique)) {
  $ext = $f.Extension.ToLowerInvariant()
  [ordered]@{
    path   = $f.FullName.Substring($PWD.Path.Length+1).Replace('\','/')
    lines  = if ($textExt -contains $ext -or $f.Name -eq '.gitignore' -or $f.Name -eq 'LICENSE') {
               [System.IO.File]::ReadAllLines($f.FullName).Count
             } else { 0 }
    bytes  = $f.Length
    sha256 = (Get-FileHash -LiteralPath $f.FullName -Algorithm SHA256).Hash.ToLowerInvariant()
  }
}

$baseline = [ordered]@{
  schemaVersion = 1
  project       = 'ForzaOverlay'
  snapshotAt    = (Get-Date).ToString('yyyy-MM-ddTHH:mm:sszzz')
  trackedRoots  = @('src/','app-dist-template/','<root files except *.log>')
  excluded      = @('**/bin/**','**/obj/**','**/.vs/**','*.log','docs/')
  fileCount     = $rows.Count
  files         = $rows
}

$json  = $baseline | ConvertTo-Json -Depth 5
$ascii = -join ($json.ToCharArray() | ForEach-Object {
  $code = [int]$_
  if ($code -gt 127) { '\u{0:x4}' -f $code } else { [string]$_ }
})
[System.IO.File]::WriteAllText((Join-Path $PWD 'docs\project-map.baseline.json'),
  $ascii, [System.Text.ASCIIEncoding]::new())
```
