# ForzaOverlay 界面统一标准

适用：主程序设置窗口（`SettingsWindow`）、HUD 布局编辑器（`HudLayoutWindow`）、以及今后新增的任何设置页与对话框。
目标：新增界面时直接照此实现，不再逐项确认。

---

## 1. 窗口

| 项 | 值 |
|---|---|
| 尺寸 | **1160 × 900 物理像素**，不可缩放、不随系统缩放变化 |
| 边框 | 无系统边框（`WindowStyle=None`），标题栏自绘 56 高 |
| 标题栏 | 左侧 `ForzaOverlay` 13px 半粗；右侧只有「最小化」「关闭」两个 40×32 按钮 |
| 最大化 | **不提供**（窗口尺寸固定） |
| 位置 | 屏幕居中 |
| 背景 | `#FFFFFF` |
| 字体 | `Microsoft YaHei UI`，全局 13px |

宽度来源：侧栏 240 + 左内边距 56 + 内容 808 + 右内边距 56 = 1160。改窗口宽度必须重算这四个数。

## 4. 版心与间距

```
标题栏 56
侧栏   240（右边线 1px #DFE1E5）
内容   左右内边距 56，顶部 28
版心   撑满可用宽度（1160−240−112 = 808），左对齐，不居中
```

| 元素 | 间距 |
|---|---|
| 页标题 → 副标题 | 10 |
| 副标题 → 首个分区标签 | 28 |
| 分区标签 → 首个设置行 | 12 |
| 设置行内边距 | 上下 22 |
| 设置行最小高度 | 92 |
| 行标题 → 行说明 | 6 |
| 行内多段说明之间 | 8 |
| 说明最大宽度 | 560（超出换行） |
| 行间分隔 | 1px `#E6E8EB` 发丝线，与版心同宽 |

## 5. 设置行（核心版式）

```
┌──────────────────────────────────────────────────────────┐
│ 行标题（15 半粗）                    [提示]   [控件]      │
│ 行说明（13，最宽 560）                                    │
├──────────────────────────────────────────────────────────┤  1px 发丝线
```

三列栅格：

| 列 | 宽度 | 内容 |
|---|---|---|
| 1 | `*` | 标题 + 说明，右侧留 40 |
| 2 | `Auto` | 行内提示（默认 `Opacity=0`，不占位但保留空间） |
| 3 | `Auto` | 控件，右对齐版心右缘 |

要点：

- 控件与说明**不居中**，一律顶部对齐
- 控件宽度固定（输入框 200、下拉 170、开关 44），不随窗口撑开
- 一个分区内的多个设置行连续排列，行间只靠发丝线分隔，不额外加卡片边框

## 6. 控件规格

### 输入框
高 34，圆角 6，1px `#D5D8DD`；悬停 `#C7CCD3`，聚焦 `#141518`；文字居中；内边距 10。

### 下拉框
高 34，圆角 6，与输入框同色系；右侧自绘箭头（`M0,0 L4,4 L8,0`，`#5A6068`，线宽 1.4）；
弹出层圆角 6、4px 内边距、选项高 32、悬停 `#F7F8F9`、选中 `#EBEEF2`；
`Focusable=False`，选完主动清焦点。

### 开关
44×24，圆角 12，滑块 18（距边 3）。
关 `#D8DBE0`；开 `#141518`；悬停各降一档（开 `#2A2C31`、关 `#C7C9CE`）；滑块位移 160ms 缓出。

### 按钮
| 类型 | 规格 |
|---|---|
| 主按钮 | 高 38，圆角 8，底 `#141518`，白字 14，左右内边距 22；按下整体下移 1px |
| 次按钮 | 高 34，圆角 6，白底 + 1px `#D5D8DD`，字 13，左右内边距 18 |
| 标题栏按钮 | 40×32，透明底，悬停 `#F7F8F9` |

### 行内提示
- 位置：设置行第 2 列，紧贴控件左侧 16
- 成功：`✓ 已生效`，绿 `#3E9E5B`，**2 秒后自动隐藏**
- 失败：具体错误文案，橙 `#F9AB00`，**常驻直到该字段成功保存**
- 两者占同一位置，同一时刻只显示一个

### 日志框
高 534，圆角 8，1px 常规描边，等宽 13px，内边距 16,14；工具条位于框体**下方**，左对齐。

## 7. 交互规则

| 规则 | 说明 |
|---|---|
| 无全局保存按钮 | 所有改动即时写盘并立即生效 |
| 文本类设置 | **失焦**时校验并提交，不在输入过程中打断 |
| 校验失败 | 不标红输入框；显示行内错误提示；输入框还原为上次生效值 |
| 布尔类设置 | 开关自身即回执，不给文字提示 |
| 下拉类设置 | 选中即提交，随后清除焦点 |
| 页面切换 | 内容区滚动位置回到顶部 |
| 分区标签不参与交互 | 只作视觉分组 |

---

## 8. 文案规则

- 使用中文全角标点（，。：、）
- 英文缩写与数字两侧留半角空格：`HUD 资源占用监测`、`60 FPS`、`512 MB`
- 主体不明时补限定词：说「HUD 渲染帧率」而不是「渲染帧率」
- 说明文字避免省略主语，句子完整、可独立阅读
- 不使用感叹号（错误提示除外）

---

## 9. 数值显示

- 界面数值最多两位小数，第三位起向零截断
- 百分比保留一位小数，内存取整并带 `MB`
- 负值只在物理意义明确时显示（如进气真空、方向盘角度）
- 单位与数值之间空一格：`23333` 不带单位；`60 FPS`、`512 MB`、`3 km/h`

---

## 10. 新增页面的检查清单

1. 页标题 24 半粗 + 一副标题
2. 分区标签用 13 半粗、颜色 `#3D424A`
3. 每个设置项都按「行标题 + 行说明 + 右侧控件」三列栅格实现
4. 控件宽度固定、右对齐版心右缘
5. 行间用发丝线，不加卡片
6. 文本类设置走失焦提交，布尔类走即时提交
7. 有提交的字段都配行内提示（成功绿 / 失败橙）
8. 新页面放进左侧导航，导航项文案不超过 6 个汉字
9. 编译 0 警告 0 错误后再交付

---

## 11. 代码约定

- 所有颜色、字号、间距写成 `Window.Resources` 里的资源，页面内不写重复字面量
- 停用某个界面元素用注释包裹并标注原因，不直接删除，便于回滚
- HUD 模块必须登记到 `HudModuleCatalog`，布局编辑器自动生成拖拽框
- 样式修改优先改资源，不在单个控件上写内联样式
- 源码内不写注释（停用标记除外）
