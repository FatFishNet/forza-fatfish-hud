Forza Fat Fish HUD 使用说明
=================================

【启动】
双击 ForzaFatFishHUD.exe，打开设置窗口。程序不置顶、不抢焦点。
关闭设置窗口即退出程序（无托盘图标）。

【游戏端设置】
1. 游戏 -> 设置 -> HUD 与游戏 -> 数据输出 (Data Out)：
   - IP 地址: 127.0.0.1
   - 端口:   23333
   - 数据输出: 开启
2. 显示模式建议使用"无边框全屏"（独占全屏会遮挡悬浮窗）。

【操作】
- F3（可在设置中修改）: 显示 / 隐藏 HUD
- 设置窗口「遥测选项」: 热键、始终显示、刷新率、面板开关、仪表样式
- 设置窗口「HUD 自定义」: 打开布局编辑器，拖动模块、拖右下角缩放、按 Enter 保存

【HUD 显示规则】
- 检测到游戏进程后，HUD 自动贴合游戏窗口的位置与大小。
- 仅在游戏窗口处于前台时显示；切到桌面或其他程序自动隐藏。
- 默认「智能显示」：需同时满足驾驶中、游戏在前台、时速高于 3 km/h，否则隐藏。
- 可在「遥测选项」切换为「始终显示」：HUD 常驻，仅由快捷键控制显示 / 隐藏。
- 按快捷键关闭遥测后，即使游戏在前台也不显示。

【仪表样式】
- SHIFT TREE：双炮筒（左转速弧、右车速 + 油门/刹车半弧）、10 颗换挡灯、中央档位
- 经典：横排仪表，含转速条、马力/扭矩/增压、档位、转速、速度、四踏板
- GHOST LADDER：几何描边仪表、分段转速条、增压条
- 轮胎与悬挂：四轮温度、抓地状态变色、悬挂行程条
- HUD 渲染资源占用：帧率 / CPU / 内存 / GPU / 显存

【红区校正】（设置 -> 遥测选项 -> 行驶仪表 -> 红区校正）
- 开启后，程序会根据发动机断油转速自动学习并校正仪表红区。
- 自动挡：找一段直线正常加速跑一次完整档位循环即可。
- 手动挡：在 1-2-3 档踩几次断油，转速保持在断油平台约 1.5 秒。
- 学习结果保存在程序目录 data\shift-learning.json，按车辆 / 最大转速 / PI 分别存档。
- 关闭该开关则不学习，红区使用固定阈值。

【换挡提示】
- 仅手动挡玩家使用：设置 -> 遥测选项 -> 行驶仪表 -> 换挡提示 -> 4灯提示。
- 4 颗灯依次表示：绿色常亮（正常）、黄灯（红区前 10%）、红灯（进入红区）、第 4 颗红灯（到达换挡点）。
- 最高档不会提示；需要先开启「红区校正」。

【超速提示音】
- 设置 -> 遥测选项 -> 轮胎与悬挂面板下方「超速提示音」。
- 可设置触发时速、响几声（3/5/10/一直响）、播放延迟、音量。
- 默认提示音：Assets\Sounds\AE86windchime.mp3；可点「选择…」换自定义 MP3。
- 「播放」按钮可预览当前设置，「停止播放」立即停止。

【刷新率】
- 60 FPS / 30 FPS / 以游戏发包为准，可在「遥测选项」切换。

【没有游戏怎么验证？】
运行 tools\模拟发送遥测数据.ps1 可持续发送模拟数据，用于验证程序与数据链路：
  powershell -ExecutionPolicy Bypass -File tools\模拟发送遥测数据.ps1
